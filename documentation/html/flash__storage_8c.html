Description détaillée

Implémentation du stockage en mémoire flash.

Implémente le stockage persistant des meilleurs scores dans la mémoire flash du microcontrôleur en utilisant la technique d'émulation EEPROM.

Documentation des fonctions

◆ flash_read_best_score()

uint32_t flash_read_best_score ( GameDifficulty difficulty)

Lit le meilleur score d'un niveau de difficulté depuis la mémoire flash.

Paramètres
difficulty- Le niveau de difficulté à lire.
Renvoie
uint32_t - Le meilleur score, ou 0 si la flash n'est pas initialisée ou corrompue.

Valide le nombre magique et la plage de scores avant de retourner la valeur. Si la mémoire flash n'a pas été initialisée, retourne 0.

Note
Les scores supérieurs à 9999 sont traités comme une corruption et retournent 0.

void flash_write_best_score ( GameDifficulty difficulty,
uint32_t score )

Écrit le meilleur score d'un niveau de difficulté dans la mémoire flash.

Paramètres
difficulty- Le niveau de difficulté à mettre à jour.
score- Le score à stocker.
Renvoie
void

Met à jour le meilleur score pour la difficulté spécifiée et préserve les scores des autres niveaux de difficulté. Efface et reprogramme la page entière de flash pour maintenir la cohérence des données.

Note
Cette fonction désactive temporairement la protection flash, modifie la page entière et réactive ensuite la protection.

Note
Disposition de la page flash 63 :
  • Décalage 0x00 : Nombre magique (0xDEADBEEF, 4 octets)
  • Décalage 0x08 : Meilleur score mode Facile (4 octets)
  • Décalage 0x10 : Meilleur score mode Moyen (4 octets)
  • Décalage 0x18 : Meilleur score mode Difficile (4 octets)
