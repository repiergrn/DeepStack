\doxysubsection{Description détaillée}
Représente l\textquotesingle{}état complet du jeu. 

Contient toutes les informations nécessaires pour exécuter le jeu, y compris la position du rectangle en mouvement, l\textquotesingle{}orientation, la pile des rectangles capturés et le score actuel.
