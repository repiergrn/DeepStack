\doxysubsection{Description détaillée}
Interface de stockage en mémoire flash pour les données de jeu persistantes. 

Fournit les fonctions pour lire et écrire les meilleurs scores pour chaque niveau de difficulté dans la mémoire flash du microcontrôleur.
