\doxysubsection{Description détaillée}
Interface de logique de jeu. 

Définit les structures et les fonctions pour gérer l\textquotesingle{}état du jeu Stack, y compris l\textquotesingle{}initialisation du jeu, la réinitialisation et la boucle de jeu principale.
